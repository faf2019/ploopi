== Module BOOKING - version 1.3.6 ====================================================

2026-10-06  Ovensia <stephane@ovensia.fr>

* Securite : les operations appliquent les droits que l'interface affiche.

  Aucune operation d'ecriture ne controlait les droits declares. Tout utilisateur
  ayant acces au module pouvait, en appelant l'operation directement :
  - creer, renommer, supprimer les types de ressources, les ressources et les
    sous-ressources (actions 10 et 11) ;
  - supprimer, deverrouiller ou valider les demandes de reservation d'autrui
    (action 20).

  Chaque operation exige desormais son action : gerer les types de ressources (10)
  pour op_resourcetype, gerer les ressources (11) pour op_resource et op_subresource,
  gerer les validations (20) pour la suppression, le deverrouillage et la validation
  d'une demande. En frontoffice, le droit s'evalue sur l'instance visee.
